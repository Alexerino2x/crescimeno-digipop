# Crescimento DigiPop

Plano, metas, decisões e rastreabilidade do crescimento comercial do DigiPop (SaaS para farmácias do Farmácia Popular) e do site [solucao.far.br](https://solucao.far.br/).

Este repositório **não tem código de produto**. Ele guarda o que decidimos, por quê, e como medimos. O trabalho técnico acontece nos repositórios de cada sistema; aqui ficam a issue mestra de cada fase e o acompanhamento.

| Repositório | Papel |
| --- | --- |
| `Alexerino2x/novo-digipop` | API (NestJS). Uptime, backup, funil, cobrança anual, indicação |
| `Alexerino2x/novo-digipop-front` | Front (Next.js) |
| `Alexerino2x/wordpress-solucao` | Site, SEO, Tag Manager, GA4, páginas de venda |
| `Alexerino2x/crescimeno-digipop` | Este: plano, metas, decisões, métricas |

## Onde está o quê

- [`PLANO.md`](PLANO.md): metas de 90 dias, 6 e 12 meses e as fases do plano.
- [`CLAUDE.md`](CLAUDE.md): regras de trabalho para pessoas e agentes.
- [`decisoes/`](decisoes/): uma decisão por arquivo, com data e motivo.
- [`metricas/`](metricas/): fechamento mensal, só números agregados.
- [`docs/issues-iniciais.md`](docs/issues-iniciais.md): issues prontas para criar.

## Estado em 07/11/2026

- MRR de R$ 14.164 em 62 assinaturas (05/11/2026). A rede de 200 seats responde por 43%.
- Meta de 12 meses: avulsos a cerca de R$ 18 mil de MRR e a rede maior abaixo de 30% do total.
